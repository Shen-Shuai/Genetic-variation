# 变异检测技术 (Variant Detection Technologies)

遗传变异的发现与鉴定依赖于多种高通量实验技术的结合。不同技术在不同变异类型上的检测能力存在本质差异——选择何种技术，取决于你想看到什么。

> **前置内容**：遗传变异的基本定义与 π 值的物理含义见 `../01_基础概念/04_遗传变异.md`；具体变异类型见 `../02_变异类型/`。

---

## 一、短读长测序 (Short-Read Sequencing)

以 **Illumina** 为代表的第二代测序技术，通过将 DNA 打断成极短片段（通常为 **150 bp**）并进行大规模并行测序。

### 优势：SNP 检测的金标准

单碱基准确度极高（错误率 **< 0.1%**），是检测 **SNP** 和 **小 indel** 的首选技术。大规模人群项目（如千人基因组、gnomAD、UK Biobank）均以短读长测序为主力平台。

### 局限性：SV 检测的盲区

由于读长太短（150 bp），短读长无法跨越基因组中的**高度重复序列**（如转座子、着丝粒、端粒区域）。在比对和组装时——如同拼一幅全是蓝天的拼图——几乎没有特征帮助算法确定碎片的确切位置。这导致：

- **结构变异（SV）误拼或漏检**：跨越重复区域的 SV 断点无法被 short reads 精确定位
- **复杂重排完全不可见**：涉及多个断点的复杂 SV 在 short-read 数据中基本无法重建

---

## 二、参考偏差 (Reference Bias)

在比对测序数据时，若样本中含有参考基因组中**不存在**的序列（如大片段插入、复杂结构变异、群体特异性等位基因），比对软件会将其误判、丢弃，或强行比对到错误的高相似度位置。

**后果**：参考偏差导致 SV 检测存在严重的**"灯下黑"**——我们只能看到与参考序列相似的"温和"变异，而忽略了真正的多样性。这在以下场景尤为严重：

- **非欧洲人群**：当前参考基因组（如 GRCh38）主要由欧洲裔个体构建，非洲等高度多样性人群中的特有等位基因和 SV 最容易被漏检
- **高度多态性区域**：MHC（人类白细胞抗原）、免疫球蛋白基因座等高度可变的区域，参考基因组仅代表了众多等位基因形式中的一种

---

## 三、线性参考基因组 (Linear Reference Genome)

### 定义与现状

将一个物种的基因组简化为一条单一的、连续的 DNA 序列——如人类的 **GRCh38**（Genome Reference Consortium Human Build 38）。

### 局限性

线性参考本质上是一个"马赛克"——由少数个体（GRCh38 主要来自约 20 个个体，且大部分来自一个非洲裔美国人 RP11 的 BAC 文库）的遗传信息拼接而成，无法涵盖物种内部的所有等位基因多样性。任何与参考"不同"的序列在被比对时都会遇到前述的参考偏差问题。

---

## 四、长读长测序 (Long-Read Sequencing)

以 **PacBio (SMRT)** 和 **Oxford Nanopore (ONT)** 为代表的第三代测序技术，能够直接读取单条 DNA 分子，长度通常达到 **10 kb 至数万 bp**，部分超长读长可达 **> 100 kb**。

### HiFi Reads：精度与长度的兼得

**PacBio HiFi (High Fidelity)** 通过将同一条 DNA 分子环化后进行循环测序（circular consensus sequencing, CCS），对多次读取取平均后消除了随机误差——实现了**长读长**（10–25 kb）与**高准确度**（**> 99.9%**，QV > 30）的兼得。

### 长读长的核心优势

由于读长足以**"跨越"复杂的重排断点和重复区域**，长读长测序在以下领域具有短读长无法替代的优势：

- **结构变异 (SV) 检测**：直接跨越 SV 断点进行全长测序，断点分辨率可达单碱基精度
- **复杂重排解析**：涉及多个断点的复杂基因组重排可在单条 read 中完整捕获
- **端到端 (T2T) 全基因组组装**：人类 T2T-CHM13（2022）完成了首个真正完整的无间隙人类基因组——包括着丝粒、端粒、核糖体 DNA 阵列等短读长无法到达的区域
- **重复序列区域**：转座子插入位点、着丝粒卫星 DNA 等在短读长中"不可见"的区域，均可被长读长覆盖

---

## 五、泛基因组 (Pangenome)

一个物种内**所有个体**基因组序列的总和——不再是一条单一的参考，而是一个涵盖群体遗传多样性全貌的"参考系统"。

### 图基因组 (Graph Genome)

泛基因组的实现形式不再是线性序列，而是一个复杂的**图（Graph）** 网络结构：

| 概念 | 说明 |
| ---- | ---- |
| **节点 (Nodes)** | 共有的 DNA 序列片段——群体中保守的序列段 |
| **边 (Edges)** | 片段之间的连接关系——当某个区域存在不同单倍型（如插入 vs 缺失）时，边分裂为多条路径 |
| **路径 (Paths)** | 不同个体的基因组序列在图基因组中表现为不同的遍历路径——每个个体的基因组是图的一个子图 |

### 优势

图基因组从根本上解决了参考偏差问题——它不再将某一个体或少数个体的基因组作为"标准"，而是将群体的所有已知等位基因多样性直接编码进数据结构。比对时，测序 reads 可以被同时比对到图的所有分支上，从而平等对待所有单倍型。人类泛基因组参考联盟（HPRC, 2023）已发布了基于 47 个多样化个体的首个人类泛基因组草图。
