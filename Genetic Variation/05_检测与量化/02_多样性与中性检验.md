# 多样性与中性检验 (Diversity Statistics & Neutrality Tests)

遗传多样性（π）的定义已在基础概念中给出。本章介绍其核心估计量、中性理论下的期望，以及用于检测偏离中性的统计检验。

> **前置内容**：核苷酸多样性 π 的定义见 `../01_基础概念/04_遗传变异.md`；溯祖理论与 $\theta = 4N_e\mu$ 的推导见 `../04_群体遗传学原理/07_溯祖理论.md`。

---

## 一、两种 $\theta$ 估计量

### Watterson 估计量 $\hat{\theta}_W$

基于**分离位点数（Segregating Sites, $S$）**：

$$\hat{\theta}_W = \frac{S}{a_1}, \quad a_1 = \sum_{i=1}^{n-1} \frac{1}{i}$$

其中 $a_1$ 为调和数——校正了样本量对分离位点数的预期影响（样本量越大，期望看到的分离位点越多）。

**逻辑**：$\hat{\theta}_W$ 仅依赖"有多少位点发生了突变"，不在乎"每个突变在多少个体中出现"——它对**等位基因频率**不敏感。

### 核苷酸多样性 $\hat{\theta}_\pi$

基于**成对序列差异（Pairwise Differences）**：

$$\hat{\theta}_\pi = \pi = \frac{\sum_{i<j} k_{ij}}{\binom{n}{2}}$$

其中 $k_{ij}$ 为序列 $i$ 和 $j$ 之间的碱基差异数，分母为所有可能的序列对数。

**逻辑**：$\hat{\theta}_\pi$ 依赖每个等位基因的**频率**——高频等位基因在成对比较中出现的次数更多，对 π 值的贡献更大。

### 中性预期下的等价性

在中性演化和恒定群体大小的标准模型下：

$$E[\hat{\theta}_\pi] = E[\hat{\theta}_W] = \theta = 4N_e\mu$$

两者的期望值相等——但它们对偏离中性的**响应方式不同**，正是这一差异催生了 Tajima's D。

## 二、等位基因频谱 (Allele Frequency Spectrum, AFS)

### 定义

AFS 描述**不同频率等位基因**的数量分布——即在一个样本中，携带频率为 $i/n$（衍生等位基因在 $n$ 条序列中出现 $i$ 次）的突变位点各有多少个。

### 中性预期

在标准中性模型下，AFS 呈**递减分布**——频率越低的变异越多：

$$E[\xi_i] = \frac{\theta}{i}$$

其中 $\xi_i$ 为衍生等位基因出现 $i$ 次的突变位点数。这意味着**singletons**（$i=1$，仅在一条序列中出现的稀有变异）应该是最多的类别。

### AFS 的偏离指示

| AFS 形态 | 指示 |
| -------- | ---- |
| 低频变异过多（singletons 过剩） | 近期**群体扩张** 或 **正选择**（扫荡产生大量新生低频变异） |
| 中频变异过多 | **平衡选择**（长期维持多态）或近期**群体收缩**（瓶颈使中频变异相对富集） |

---

## 三、Tajima's D

### 统计量

$$D = \frac{\hat{\theta}_\pi - \hat{\theta}_W}{\sqrt{\widehat{\text{Var}}(\hat{\theta}_\pi - \hat{\theta}_W)}}$$

Tajima's D 比较两种 $\theta$ 估计量——它们的差异揭示了等位基因频率分布是否偏离中性预期。

### 解读

| D 值 | $\hat{\theta}_\pi$ vs $\hat{\theta}_W$ | AFS 形态 | 可能原因 |
| ---- | ---------------------------------------- | -------- | -------- |
| **$D \approx 0$** | 两者接近 | 符合中性预期 | 中性演化 |
| **$D < 0$** | $\hat{\theta}_\pi < \hat{\theta}_W$ | 低频变异过多 | **正选择**（选择性扫荡后新突变开始积累）、**净化选择**、近期群体**扩张** |
| **$D > 0$** | $\hat{\theta}_\pi > \hat{\theta}_W$ | 中频变异过多 | **平衡选择**（杂合子优势等长期维持多态）或近期**群体收缩**（瓶颈效应） |

**机制解释**：正选择扫荡清除了原有变异后，新突变大多处于极低频率（仅出现在 1-2 条序列中）。这些 singletons 对 $\hat{\theta}_W$ 的贡献和对 $\hat{\theta}_\pi$ 的贡献不同——$\hat{\theta}_\pi$ 更"看重"中频变异（中频变异出现在更多的成对比较中），因此扫荡后的 $\hat{\theta}_\pi < \hat{\theta}_W$，$D < 0$。

### 答题步骤

1. 数出分离位点数 $S$，计算 $a_1 = \sum_{i=1}^{n-1} 1/i$，得 $\hat{\theta}_W = S / a_1$
2. 计算所有 $\binom{n}{2}$ 个序列对的平均差异数，得 $\hat{\theta}_\pi$
3. 计算 $D$（分母通常由题目给出或只要求判断正负方向）

### 例题

4 条序列（$n=4$），$S=5$，成对差异：4+5+3+1+3+2=18：

- $a_1 = 1 + 1/2 + 1/3 = 11/6 \approx 1.833$，$\hat{\theta}_W = 5 / 1.833 \approx 2.73$
- $\hat{\theta}_\pi = 18 / \binom{4}{2} = 18 / 6 = 3$
- $\hat{\theta}_\pi > \hat{\theta}_W$ → $D > 0$ → 中频变异偏多，与**平衡选择**或**群体收缩**一致
