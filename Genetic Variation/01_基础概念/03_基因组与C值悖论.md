# 基因组与 C 值悖论

## 一、基因组

### 基因组定义

生物体**全部遗传信息的总和**，包含所有编码与非编码序列。

### 人类基因组数据基准

| 指标 | 数值 |
| ---- | ---- |
| 大小 | 约 **3.2 × 10⁹ bp**（3.2 Gb） |
| 蛋白编码基因 | 约 **2 万个** |
| 染色体 | **46 条**（23 对） |

### 基因组的结构悖论

编码区仅占基因组 **1%–2%**，绝大多数序列由非编码 DNA 组成（详见 `02_基因组结构.md` 第二部分），主要包括内含子、调控元件、转座子等。这种"编码区占比极小"的结构特征，与下文 C 值悖论密切相关。

### 核型 (Karyotype)

指一个物种或个体细胞内染色体的**数目、大小和形态特征**的总和。

- 人类核型：46 条染色体（23 对），包括 22 对常染色体 + 1 对性染色体 (XX/XY)
- 核型是物种基因组在**染色体层面**的"快照"，可用于检测染色体数目异常（如非整倍体）和结构重排

### 染色体数目的悖论

与 C 值悖论类似，**单倍体染色体数（n）的大小并不代表物种的"进化等级"或复杂性**：

| 物种 | 单倍体数 (n) | 说明 |
| ---- | ------------ | ---- |
| 蕨类 (*Ophioglossum*) | **630** | 已知染色体最多的生物之一，但远不如人类复杂 |
| 人类 | 23 | — |
| 印度麂 (*Muntiacus muntjak*) | **3–4**（雌 3 / 雄 4） | 哺乳动物中染色体数最少；其近缘种小麂 (*M. reevesi*, n=23) 在演化中经历了**大规模串联融合**，将分散的遗传物质"打包"进极少数巨型染色体 |
| 跳蚁 (*Myrmecia pilosula*) | **1** | 已知染色体数最少的动物；其近缘物种拥有较多染色体，说明融合与裂变在蚁科演化中非常活跃 |

> **延伸阅读**：染色体融合与裂变是染色体变异的重要类型，详见 `../02_变异类型/03_结构变异与染色体变异.md`。

## 二、C 值悖论

### C 值悖论的定义

物种基因组大小（C 值）与生物体的解剖/生理复杂程度之间**不存在**简单的正相关关系。

### 现象

某些原始两栖类或植物的基因组比人类大出数十倍，但其生理复杂性并未按比例增加。

### 科学解释

- 生物复杂性更多来源于**基因调控网络**的精密程度、**可变剪接**的多样性以及**发育机制**的复杂化
- 基因组大小的膨胀往往由**重复序列**（如转座子）的堆积造成，而非功能基因数量的增加
