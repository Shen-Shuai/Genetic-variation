# 插入缺失 (Insertion-Deletion, Indel)

## 一、定义与发生机制

**Indel** 是"插入"（Insertion）与"缺失"（Deletion）的合称，指基因组中短片段 DNA（通常 **< 50 bp**）的增加或丢失。

**遗传地位**：在人类基因组中，Indel 的数量仅次于 SNP，是造成个体间遗传差异和表型多样性的重要变异来源。

### 发生机制：复制滑移 (Replication Slippage)

Indel 最常见于**微卫星重复序列（Microsatellites / Short Tandem Repeats, STRs）** 区域。其核心机制为 DNA 聚合酶在复制过程中的**链滑动错配（Slipped-Strand Mispairing）**——当聚合酶遇到串联重复序列时，新合成链与模板链之间可能发生短暂解离并重新配对，因重复单元的序列相同，重新配对时可能产生"错位"：

- 若新合成链向后退一格（loop-out on the nascent strand）→ **插入**（多复制了一份重复单元）
- 若模板链向前推一格（loop-out on the template strand）→ **缺失**（跳过了模板上的一份重复单元）

## 二、编码区 Indel 的分类

Indel 发生在编码区时，其功能后果取决于插入/缺失的碱基数是否为 **3 的倍数**（即是否保持密码子阅读框）。

### 1. 整码突变 (In-frame Indel)

**特征**：插入或缺失的长度为 **3n bp**（如 3, 6, 9 bp）。

- **阅读框保留**：突变位点下游的所有密码子不受影响，翻译过程不受破坏
- **功能影响**：仅在突变位点增加或缺失若干氨基酸，蛋白质整体结构通常得以保留；功能可能部分减弱或改变，但很少完全失活
- **演化意义**：整码 indel 是实现蛋白功能微调（如结构域伸缩、柔性区域长度调整）的常见方式

### 2. 移码突变 (Frameshift Mutation)

**特征**：插入或缺失的长度为 **≠ 3n bp**（如 1, 2, 4 bp）。

**双重遗传后果**：

- **全局重写**：突变点之后的所有密码子阅读框全部改变，氨基酸序列完全错乱
- **提前终止**：极大概率在下游随机产生**提前终止密码子（Premature Termination Codon, PTC）**，导致翻译在正常终止位点之前结束——蛋白被截断，通常意味着功能的**彻底丧失（Null Mutation / Loss of Function）**

### 3. 移码校正 (Frameshift Correction)

移码突变并非总是死路一条。在罕见的演化场景中，两个补偿性 indel 可以恢复阅读框：

- **机制**：若一个移码突变（如 +1 bp）发生后，其下游不远处再次发生另一个 Indel（如 -1 bp 或 +2 bp），使得**总碱基偏差重新回到 3 的倍数**
- **结果**：阅读框在第二个位点之后被**校正**回原始状态——两个突变点之间的氨基酸序列发生了改变，但蛋白质剩余部分的功能可能得以部分保留

这种二次校正的"分子疤痕"在比较基因组学中被用于追溯古代表达框移位的演化轨迹。

## 三、经典案例：CCR5-Δ32 突变

### 突变详情

- **本质**：$CCR5$ 基因编码区发生了 **32 bp 的缺失**（Δ32）
- **分子后果**：32 不是 3 的倍数 → 典型**移码突变** → 产生大量错义氨基酸和 PTC → CCR5 受体蛋白无法正常表达或定位至细胞膜

### HIV 抗性

CCR5 蛋白是 HIV-1 病毒进入 CD4⁺ T 细胞的主要共受体（R5 嗜性毒株）。Δ32 突变使该"入口"从细胞表面消失：

| 基因型 | 表型 |
| ------ | ---- |
| **纯合子 (Δ32/Δ32)** | 几乎完全阻断 R5 型 HIV 的感染（仍需警惕 X4 嗜性毒株） |
| **杂合子 (WT/Δ32)** | 感染后病毒载量较低，病程进展速度显著减慢 |

### 群体分布与演化之谜

Δ32 在欧洲人群中频率较高（约 **10%** 的等位基因频率），而在亚洲和非洲人群中极为罕见。这一分布模式引发了关于其演化驱动力的长期争论：

1. **正选择假说**：历史上欧洲可能经历了某种强烈的传染病选择压力——CCR5-Δ32 赋予了存活优势。候选病原体包括**鼠疫耶尔森菌**（黑死病）、**天花病毒**等——两者均以欧洲为主要疫区，且 CCR5 与免疫响应有关联
2. **中性演化 + 奠基者效应假说**：部分学者认为 Δ32 在欧洲的高频可能仅是**奠基者效应**和随机遗传漂变的结果，而非正选择

**核心争论点**：Δ32 突变估算的出现时间（基于 LD 衰减推算可能超过 5000 年）与黑死病（~700 年前）或天花大流行的时间线是否吻合，目前仍无定论。
