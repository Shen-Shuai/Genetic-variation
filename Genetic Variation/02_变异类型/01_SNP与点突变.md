# SNP 与点突变 (SNP / Point Mutation)

## 一、定义与遗传地位

### 物理本质

**SNP (Single Nucleotide Polymorphism)** 是指在基因组水平上，由单个核苷酸（A、T、C、G）的**置换（Substitution）** 所引起的 DNA 序列多态性——即基因组序列中特定位置的"字母"发生了改变（如从 A 变为 G）。

### 遗传地位

SNP 是人类基因组中**最常见、数量最多**的遗传变异类型，占所有已知遗传多态性的 **90% 以上**。单个人类基因组相对于参考基因组约含有 **400–500 万个 SNP**，平均约每 1000 bp 出现 1 个 SNP（与人类 π ≈ 0.001 直接对应）。

### SNP vs SNV：等位基因频率的分界线

并非所有单核苷酸改变都能被称为"多态性"。在群体遗传学中，通常根据**次要等位基因频率（Minor Allele Frequency, MAF）** 划分：

| 术语 | 英文 | 频率阈值 | 含义 |
| ---- | ---- | -------- | ---- |
| **SNP** | Single Nucleotide Polymorphism | **MAF ≥ 1%** | 在群体中稳定存在的常见变异，通常被认为是演化过程中保留下来的遗传标记 |
| **SNV** | Single Nucleotide Variant | **MAF < 1%** | 频率极低的稀有变异，可能为新发突变（de novo mutation），尚未在群体中扩散 |

这一区分在医学遗传学中有直接应用——GWAS 主要捕获的是 SNP（常见变异），而罕见病和部分复杂疾病的"缺失遗传力"可能隐藏于 SNV 中。

### 基因组位置分类：cSNP 与 nSNP

根据 SNP 在基因组中的位置，可将其分为两大类——这直接影响其功能后果的解读框架：

| 类型 | 英文 | 位置 | 潜在功能影响 |
| ---- | ---- | ---- | ------------ |
| **编码区 SNP (cSNP)** | Coding SNP | 外显子（Exon） | 直接影响蛋白质序列 → 同义/错义/无义突变 |
| **非编码区 SNP (nSNP)** | Non-coding SNP | 内含子、基因间区、调控区域 | 影响**表达调控**——增强子、启动子、剪接位点、绝缘子等 |

cSNP 的功能后果见 `../../06_功能与演化/01_编码区变异的功能后果.md`；nSNP 的大多数 GWAS 显著位点位于非编码区，其功能解读依赖调控元件注释和 3D 基因组信息。

## 二、转换与颠换

根据碱基的化学结构类别，SNP 可分为两类：

### 转换 (Transition)

同类化学结构碱基之间的互换，在碱基随机替换背景下共有 **4 种**可能路径：

- **嘌呤 ↔ 嘌呤**（双环 ↔ 双环）：$A \leftrightarrow G$
- **嘧啶 ↔ 嘧啶**（单环 ↔ 单环）：$C \leftrightarrow T$

转换是 SNP 中**最常见**的类型。其普遍性根源于碱基的**分子对称性**：

- **结构高度相似**：替换前后的碱基化学结构几乎一致（环数相同、骨架形状相近），DNA 双螺旋仅产生微小几何扰动
- **空间位阻小**：双螺旋内部空间变形轻微，DNA 聚合酶的 **3'→5' 校对机制（proofreading）** 难以识别和清除——这恰好与颠换的高拦截率形成对比
- **错误率高**：正因化学性质接近，复制或修复时细胞更容易将其"张冠李戴"

这种天然的高发生率使转换成为 SNP 的主体，同时由于转换多发生在密码子第三位（简并位），其功能影响通常较颠换更温和。

### 颠换 (Transversion)

不同类化学结构碱基之间的互换——**嘌呤 ↔ 嘧啶**：

$$A \leftrightarrow C,\quad A \leftrightarrow T,\quad G \leftrightarrow C,\quad G \leftrightarrow T$$

颠换具有以下几项关键特征：

**数学冗余但实际稀少**：在碱基随机替换的概率模型中，颠换共有 **8 种**可能路径（是转换路径数 4 种的 2 倍），但自然突变中颠换的频率**远低于**转换。原因在于：

- **空间位阻大**：涉及单环（嘧啶）与双环（嘌呤）结构的更替——在 DNA 双螺旋的有限空间内，这种体积的显著改变引起骨架剧烈扭曲
- **化学能垒高**：由于分子结构差异巨大，此类替换在 DNA 复制或修复过程中极易被校对机制（proofreading）识别并拦截

**功能影响更剧烈**：由于遗传密码子的演化设计，密码子第三位（简并位）通常对转换具有较高容忍度——同义突变多为转换。而颠换更可能改变密码子编码的氨基酸种类，导致**非同义突变**，且由此产生的氨基酸替换（如疏水 → 亲水）更可能导致蛋白质折叠异常或功能丧失。

### 转换/颠换比 ($Ts/Tv$ Ratio)

$Ts/Tv$ 是衡量 SNP 构成质量和序列演化压力的核心指标。在随机模型下，颠换有 8 种路径、转换有 4 种路径，理论期望比为 **$Ts/Tv = 0.5$**——但自然基因组中该比值**远高于此**。

**人类基因组实测**：在人类基因组或近缘物种比较中，$Ts/Tv$ 通常 **> 2**，即转换的发生频率是颠换的 2 倍以上。这一"转换优势"（Transition Bias）是化学偏向与自然选择共同作用的结果。

| $Ts/Tv$ | 含义 | 场景 |
| ------- | ---- | ---- |
| **> 2**（正常值） | 转换优势——符合自然演化规律，序列受到选择压力（纯化选择剔除有害颠换） | 外显子区域、功能保守基因 |
| **≈ 0.5**（危险值） | 接近随机期望——暗示极高中性演化状态，或测序/变异检测中存在**大量随机噪声/假阳性** | 假基因区域；测序质量差时的"变异"调用结果 |

**基因组区域差异**：外显子（Exon）区域的 $Ts/Tv$ 通常**远高于**内含子（Intron）和基因间区。原因在于：外显子对颠换引起的非同义突变极其敏感——颠换→非同义→有害→被纯化选择清除→在外显子中稀少。而转换（多为同义或保守错义）在外显子中的存在率相对较高。因此，**$Ts/Tv$ 本身就是一个"功能区探测器"**——低 $Ts/Tv$ 的区域要么不受选择约束，要么数据质量有问题。

> **前置内容**：遗传变异的总体定义见 `../01_基础概念/04_遗传变异.md`；密码子简并性如何容忍第三位的转换但不一定容忍颠换，见 `../01_基础概念/02_基因组结构.md`"简并性"与"三个碱基位点的效应差异"两节；突变的产生机制见 `../03_突变与重组/01_突变的分子机制.md`。

## 三、多核苷酸变异 (Multi-Nucleotide Variant, MNV)

**MNV** 指在基因组极其接近的距离内（通常是相邻或仅隔几个碱基），**同时发生**两个或多个碱基置换的现象。

与多个独立 SNP 在基因组上偶然相邻不同，MNV 的核心特征是**同源单一突变事件（Co-mutation）**——几个碱基在一次事件中被同时引入。其位点高度聚集（clustered），通常仅跨越几个碱基的距离。

### 产生机制

MNV 的产生与 DNA 复制过程中的"容错机制"有关：

1. **易错聚合酶 (Error-prone Polymerase) 的跨损伤合成**：在 DNA 损伤修复过程中，特殊的 DNA 聚合酶——如 **Pol ζ (POLZ)**——负责执行**跨损伤合成（Translesion Synthesis, TLS）**。这类聚合酶为保证复制不中断而**牺牲了精准度**——其活性位点更宽松，在通过损伤位点时容易连续引入多个错误碱基匹配，在一次复制事件中产生成簇的替换
2. **协同修复错误**：根据 **Assaf et al. (2017)** 等研究，协同突变（co-mutation）事件在人类生殖细胞系中约占 **1%–3%** 的替换变异——虽不是主流，却是驱动基因组复杂性和新功能演化的不可忽视的来源

### 临床注释陷阱

常规变异检测流程通常将相邻的多个单碱基改变拆分为独立的 SNP，而非将其识别为一个整体的 MNV。但将 MNV 错误拆分为多个独立 SNP 会严重干扰功能注释——例如，两个独立的同义 SNP 各自被标注为"无影响"，但作为整体的 MNV 可能产生非同义的氨基酸替换（因为不是每个单独的碱基而是整体的密码子表发生了改变）。因此，在临床变异解读中，对聚集性 SNV 进行正确的 MNV 统一注释至关重要。
