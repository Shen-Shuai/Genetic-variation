# 选择扫荡 (Selective Sweep)

选择扫荡是正选择（positive selection）作用于有利突变后，在基因组上留下的特征性多样性缺失信号。

## 机制

当一个新产生（或低频存在）的有利等位基因在群体中频率快速升高并最终固定时，其**周围连锁区域**的遗传多样性被一并"扫除"——这一现象称为**选择扫荡**。

扫荡在基因组上留下的是**局部低 π 值**特征：受选择位点及其连锁的周边区域，由于搭车效应导致多样性急剧下降，与周围未受影响的区域形成鲜明对比。这种"局部多样性低谷"是检测正选择信号的经典标志之一。

### 搭车效应 (Genetic Hitchhiking)

与有利等位基因处于**连锁不平衡 (Linkage Disequilibrium, LD)** 状态的中性（甚至轻微有害）变异，会随着有利变异的频率升高而"搭车"上升。扫荡完成后，受选择位点附近的多样性降至极低水平。

#### 经典案例：Mutator 基因的强制扩张

搭车效应最震撼的案例之一，是**Mutator 基因**（自身为修复缺陷，属于有害突变）通过创造并绑定有益突变而实现"强制扩张"：

1. **绑定效应**：一个携带修复缺陷（如 *mutS*⁻）的细菌个体，其基因组突变率大幅升高（100–1000×）。在抗生素压力下，这个 Mutator 恰好创造了一个耐药性有益突变——二者处于**同一基因组**上，形成强烈的**物理连锁**（LD ≈ 1，两者永不分离）
2. **选择扫荡**：自然选择筛选的是"耐药性"这一表型——但当它抬升耐药等位基因的频率时，物理连锁的 Mutator 基因也被一并"打包"保留并推向固定
3. **结论**：Mutator 并不因其自身的优越性而存在（实际上它降低了适合度），而是通过与其创造的"适应性奇迹"**捆绑销售**，实现了在群体中的强制扩张

这一案例揭示了搭车效应的一个关键延伸——**选择的"盲区"**：自然选择只能"看见"表型（耐药性），却无法识别与有利突变连锁的基因是好是坏。只要连锁足够紧密，一个有害突变可以搭上正选择的"顺风车"。这也解释了为什么修复缺陷基因在细菌群体中并非罕见——它们通过周期性地创造并绑定有益突变而反复"复活"。

> **前置内容**：π 值的定义与选择扫荡对多样性的影响见 `../01_基础概念/04_遗传变异.md`"π 值的群体遗传学解读"小节；连锁不平衡 (LD) 的定义与度量见 `05_连锁不平衡.md`。

## 二、硬扫荡与软扫荡

上述经典描述（单一起源有利突变 → 扫除周围多样性）实际上只描述了扫荡的一种模式——**硬扫荡 (Hard Sweep)**。扫荡的模式取决于有利突变的来源。

### 硬扫荡 (Hard Sweep) — 从"一个"到"全部"

| 维度 | 特征 |
| ---- | ---- |
| **突变来源** | **单一新发突变 (de novo)**——有利等位基因在群体中仅出现一次 |
| **频率轨迹** | 从极低频率（1 个拷贝）→ 正选择推动 → 快速固定（100%） |
| **基因组信号** | 受选择位点周围大片区域多样性**彻底丧失**——因为只有一个原始单倍型背景 |
| **典型群体** | $N_e$ 巨大的物种（如细菌、果蝇）——群体中每一代都穷尽了几乎所有可能的点突变，"等待"一个幸运的有益突变即可 |

### 软扫荡 (Soft Sweep) — 从"多个"到"一个"

| 维度 | 特征 |
| ---- | ---- |
| **突变来源** | **现有变异 (Standing Genetic Variation)**——有利等位基因在环境变化**之前**就以中性或微害状态存在于群体中（多个独立拷贝或多个不同单倍型背景） |
| **频率轨迹** | 从已有中等频率 → 正选择推动 → 固定 |
| **基因组信号** | 多样性降低但**不完全清除**——因为有利等位基因原本存在于多个不同的单倍型背景上，选择同时抬升了这些不同的背景 |
| **典型群体** | $N_e$ 较小的物种（如人类、脊椎动物）——个体数量有限，无法依赖新发突变"现造"，只能依赖群体中早已存在的遗传库存 |

### 区分的关键意义

硬扫荡和软扫荡在基因组上留下的选择信号截然不同——硬扫荡是"全清"，软扫荡是"部分清除"。这对选择检测方法的选择有直接影响：基于"全清"假设的统计量（如 CLR, Fay & Wu's H）对软扫荡的检测功效显著降低。

## 三、$N_e$ 如何决定适应的遗传模式

硬扫荡与软扫荡的对立，根源在于有效群体大小 $N_e$——它决定了自然选择与漂变的相对力量，进而决定了适应进化依赖的遗传原料和扫荡模式：

| 维度 | **大 $N_e$（单细胞生物）** | **小 $N_e$（多细胞生物）** |
| ---- | ------------------------- | ------------------------- |
| **主导演化力量** | **自然选择**（确定性的） | **遗传漂变**（随机的） |
| **适应速率** | 极快（爆发式） | 较慢（渐进式） |
| **遗传原料** | **新发突变 (de novo)**——群体基数巨大，每一代几乎穷尽所有可能的点突变 | **现有变异 (standing variation)**——依赖群体中早已存在的低频率中性/微害变异，在环境变化时转为有利 |
| **扫荡类型** | **硬扫荡** (Hard Sweep) | **软扫荡** (Soft Sweep) |
| **演化确定性** | 高——环境明确决定结果 | 低——偶然性（漂变）影响大 |
| **选择灵敏度** | $s$ 极小即可被选择捕获 | 需 $s > 1/N_e$ 才能超越漂变噪音 |

**核心逻辑**：在细菌群体中（$N_e > 10^9$），即使突变率极低（~10⁻¹⁰/bp/代），每个位点在每一代中都有多个个体携带新突变，环境压力一来"总有几个恰好有救命突变"。在人类群体中（$N_e \approx 10^4$），新发突变极其有限，适应更多依靠"翻库存"——早已存在的低频变异在新环境下变为有利。

> **延伸阅读**：$N_e$ 决定选择-漂变边界（$s$ vs $1/N_e$）的定量分析见 `02_遗传漂变与有效群体大小.md` 第四节。

## 四、搭车效应的定量范围

搭车效应影响的范围由**选择强度与重组率的比值**决定：

$$\text{多样性降低区域} \sim \frac{s}{r}$$

- $s$（选择系数）越大 → 扫荡越快 → 重组来不及拆散连锁 → 影响范围越大
- $r$（重组率）越高 → 连锁被打散越快 → 影响范围越小
- 在重组率极低的区域（如着丝粒附近、倒位多态区），一次强扫荡可清除数百 kb 至数 Mb 的多样性

## 五、检测选择扫荡的方法

### 基于多态性与分化

| 方法 | 原理 | 信号 |
| ---- | ---- | ---- |
| **Tajima's D** | $\pi$ vs $\theta_W$ 差异 | $D < 0$：低频变异过多 → 正选择/扩张 |
| **$F_{ST}$ outlier** | 局部位点 $F_{ST}$ 异常高于全基因组背景 | 局域适应性进化 |
| **$d_N/d_S (\omega)$** | 非同义 vs 同义替换率 | $\omega > 1$：正选择 |

> Tajima's D 的详细原理见 `../../05_检测与量化/02_多样性与中性检验.md`。

### 基于单倍型与连锁不平衡（检测近期扫荡）

当正选择发生的时间足够近（< 0.1 $N_e$ 代），被选择的等位基因周围的单倍型同质性尚未被重组完全打散——此时基于单倍型的方法最为灵敏：

| 方法 | 全称 | 原理 |
| ---- | ---- | ---- |
| **EHH** | Extended Haplotype Homozygosity | 度量有利等位基因周围单倍型同质性向外延伸的距离——延伸越长 → 扫荡越新/越强 |
| **iHS** | integrated Haplotype Score | 在同一群体内比较衍生等位基因与祖先等位基因的 EHH 衰减曲线——哪一个等位基因周围的单倍型延伸更远？ |
| **XP-EHH** | Cross-Population EHH | 跨群体比较——检测在某一群体中已近固定（hard sweep）但另一群体中仍多态的选择信号 |
| **nSL** | Number of Segregating sites by Length | iHS 的改进版——用分离位点数而非遗传距离衡量单倍型延伸，对重组率估计误差更稳健 |

**iHS 的解读**：

| iHS 方向 | 含义 |
| -------- | ---- |
| 极正 iHS | 衍生等位基因周围的单倍型显著长于祖先 → 该衍生等位基因受近期正选择 |
| 极负 iHS | 祖先等位基因周围单倍型更长 → 可能为背景选择或该位点附近有其他受选择位点 |
| iHS ≈ 0 | 两种等位基因的单倍型延伸相当 → 无近期扫荡信号 |

> 详细内容见 `../../05_检测与量化/02_多样性与中性检验.md` 及群体遗传学专门文献。
