# 哈代-温伯格平衡 (Hardy-Weinberg Equilibrium, HWE)

HWE 是群体遗传学的理论基石，描述了**在理想条件下**等位基因频率与基因型频率之间的关系。

> **前置内容**：等位基因频率与核苷酸多样性 π 的定义见 `../01_基础概念/04_遗传变异.md`。

---

## 一、HWE 的推导与假设

### 五大假设

HWE 基于以下理想化条件：

1. **随机交配（Random Mating）**：群体中任何两个异性个体结合的概率完全均等
2. **无限大群体**：排除遗传漂变的影响
3. **无突变**：没有新的等位基因产生
4. **无迁移（基因流）**：没有个体迁入或迁出
5. **无自然选择**：所有基因型具有相同的适合度

### 基因型频率推导

设等位基因 A 频率为 $p$，a 频率为 $q$（$p + q = 1$）。在随机交配下：

$$f(AA) = p^2,\quad f(Aa) = 2pq,\quad f(aa) = q^2$$

$$p^2 + 2pq + q^2 = 1$$

### 由基因型频率反推等位基因频率

$$p = f(AA) + \frac{1}{2}f(Aa)$$

## 二、HW 平衡检验：卡方检验

判断观测群体是否偏离 HW 平衡的标准方法是**卡方拟合优度检验**：

$$\chi^2 = \sum \frac{(O - E)^2}{E}, \quad df = 1$$

其中 $O$ 为各基因型的观测计数，$E$ 为 HW 期望计数（$E = n \times$ 期望频率）。

### 常见偏离原因

| 偏离方向 | 可能原因 |
| -------- | -------- |
| 杂合子亏缺 | 近亲繁殖、群体结构（Wahlund 效应）、近交 |
| 杂合子过剩 | 远交（outbreeding）、杂合子优势 |
| 整体偏离 | 选择、迁移、非随机交配、有限群体大小的漂变 |

### 例题

某群体中观测到 AA=360，Aa=480，aa=160（共 1000 人），判断是否处于 HW 平衡。

**解**：

$$p = \frac{2 \times 360 + 480}{2 \times 1000} = 0.6,\quad q = 0.4$$

期望频率：$E(AA) = 0.36 \times 1000 = 360$，$E(Aa) = 0.48 \times 1000 = 480$，$E(aa) = 0.16 \times 1000 = 160$

$$\chi^2 = 0 \Rightarrow \text{符合 HW 平衡}$$

## 三、Wahlund 效应

将**遗传结构化**的多个亚群混合为一个样本后，即使各亚群自身均处于 HW 平衡，混合后的观测杂合度也会**低于**基于混合等位基因频率计算的 HW 期望杂合度。

$$\text{杂合度亏缺} = 2 \text{Var}(p)$$

其中 $\text{Var}(p)$ 为各亚群中等位基因频率的方差。亚群间频率差异越大，Wahlund 效应越显著。

**例题**：两个亚群频率分别为 $p_1=0.6$，$p_2=0.2$，混合后 $\bar{p}=0.4$。

- 各亚群内观测杂合度：$H_1 = 2 \times 0.6 \times 0.4 = 0.48$，$H_2 = 2 \times 0.2 \times 0.8 = 0.32$
- 混合后观测杂合度（各亚群均值）：$\bar{H}_{obs} = \frac{0.48 + 0.32}{2} = 0.40$
- 混合期望杂合度：$H_T = 2 \times 0.4 \times 0.6 = 0.48$
- $H_{obs} = 0.40 < H_T = 0.48$ ✓——Wahlund 效应验证
