# 遗传漂变与有效群体大小 (Genetic Drift & Effective Population Size)

## 一、遗传漂变 (Genetic Drift)

遗传漂变是指由于**有限群体中配子的随机抽样误差**，导致等位基因频率在世代间随机波动的现象。

与自然选择不同，漂变是**非选择性**的——等位基因频率的改变与基因的"优劣"或个体的适应度（fitness）完全无关。在有限群体中，漂变是不可避免的，其强度与群体大小成反比：群体越小，漂变越强。

HWE 的假设之一是"无限大群体"，正是为了排除漂变的影响。现实中所有群体都是有限的，因此漂变是普遍存在的演化力量。

### 漂变的概率本质

漂变的核心是**小样本下的随机误差**。就像抛一枚公平硬币，理论概率是正反面各 50%，但如果只抛 5 次，完全可能出现 5 次全是正面。在遗传学中，这种"小样本误差"就是漂变——每一代存活并繁殖的个体只是上一代基因库的一个有限样本。

由于漂变与适应性无关，其演化后果是盲目的：

- **有利突变可能因"运气不好"而消失**：一个具有选择优势的等位基因，若恰好出现在少数个体中，可能仅因随机抽样而在早期世代丢失。
- **中性甚至微害突变可能因"运气好"而固定**：在小群体中，随机波动足以让一个对适应性无贡献（或轻微有害）的等位基因频率"漂"到 100%。

正是这种不可预测性，使漂变成为塑造小群体遗传结构的主导力量之一。

## 二、有效群体大小 (Effective Population Size, $N_e$)

### 定义

$N_e$ 指在一个**理想化群体**（随机交配、数量恒定、无选择、无群体结构）中，能产生与观测群体相同**遗传漂变**水平的个体数量。

简言之，$N_e$ 不是"群体中有多少个体"（那是普查群体大小 census population size, $N_c$），而是"群体在遗传上表现得有多大"。

### 为什么 $N_e \neq N_c$

实际群体中，多种因素使 $N_e$ 远小于 $N_c$：

| 因素 | 机制 | 对 $N_e$ 的影响 |
| ---- | ---- | --------------- |
| 性别比例不均衡 | 繁殖个体中雌雄比例偏离 1:1 | $N_e = \frac{4N_m N_f}{N_m + N_f}$，极端偏比时 $N_e \ll N_c$ |
| 群体大小波动 | 历史上曾经历瓶颈（小种群阶段） | $N_e$ 趋近于**调和平均数**，受最小值主导 |
| 繁殖成功率差异 | 部分个体不参与繁殖或后代数差异大 | 降低 $N_e$ |
| 世代重叠 | 不同年龄个体同时存在于群体中 | 调整计算方式 |

### $N_e$ 与 π 的关系

在**中性演化**假设下，群体的核苷酸多样性期望值为：

$$\pi = 4 N_e \mu$$

其中 $\mu$ 为每个位点每代的突变率。这意味着：
- π 值直接反映了 **$N_e$ 与突变率的乘积**——$N_e$ 越大，新突变越多，平衡时的多样性越高
- 人类的低 π 值（≈ 0.001）可以部分归因于较小的长期 $N_e$（约 10,000–15,000，远小于普查人口）

> **延伸阅读**：瓶颈效应是 $N_e$ 骤降的典型案例，见 `../01_基础概念/04_遗传变异.md` 第三节。

## 三、人类案例：$N_e$ 如何塑造了我们的基因库

人类的核苷酸多样性（π ≈ 0.001）远低于黑猩猩等近缘灵长类（后者约为人类的 2–3 倍），其根本原因在于人类的长期 $N_e$ 较小。尽管当今全球人口已达 80 亿，但这一大规模扩张发生在极短的进化时间内——**新突变的积累尚不足以填补历史瓶颈期造成的变异损失**。

### 历史链条："走出非洲"前后的瓶颈印记

现代人类的演化史（尤其是约 10 万年前走出非洲前后）经历了剧烈的人口缩减，形成了一条清晰的因果链：

```text
人口骤减 → 随机漂变加剧 → 稀有等位基因丢失 → 遗传多样性被"压缩"
```

1. **人口骤减**：环境压力（如气候波动）或迁徙事件（如奠基者效应 Founder Effect）导致有效繁殖群体数量急剧下降
2. **随机漂变加剧**：在小群体中，等位基因频率的跨代波动完全由随机因素主导——个体是否留下后代更多取决于运气而非适应性
3. **等位基因丢失**：大量稀有等位基因（rare alleles）在抽样漂变中永久消失，基因库被不可逆地削减
4. **遗传多样性"压缩"**：这种损失并非表面现象，而是烙印在现代人类基因组的底层结构中——全基因组范围内的 π 值被压至极低水平

### 关键洞见：普查人口 ≠ 遗传有效群体

即使普查人口（$N_c$）已恢复甚至爆炸性增长，但**突变积累需要时间**。$\pi = 4N_e\mu$ 所描述的平衡是长期演化的结果——新突变以极低的速率（~10⁻⁸ /位点/代）产生，要在全基因组尺度重新建立高多样性，需要数万至数十万代的时间尺度。因此，现代人类的基因组仍然是那次远古瓶颈的"活化石"。

> **前置内容**：人类 π 值的具体数值与跨物种比较见 `../01_基础概念/04_遗传变异.md`"人类基因组的 π 值"小节；瓶颈效应的机制定义见同文件第三节。

### 迁徙路径的遗传印记：π 梯度与连续奠基者效应

走出非洲不仅是一次瓶颈——它是一个**连续奠基者效应（Serial Founder Effect）** 的级联过程。通过观察全球人群的 π 值梯度，可以清晰还原人类的迁徙路径：

**核心规律：离非洲越远，π 值越低。**

| 地理区域 | π 值相对水平 | 原因 |
| -------- | ------------ | ---- |
| 非洲（撒哈拉以南） | **最高** | 人类起源地，保留了最完整的祖先遗传多样性 |
| 中东 / 欧洲 | 中等 | 走出非洲后的第一站，仅携带了非洲基因库的一个"子集" |
| 东亚 | 较低 | 经过多次奠基者抽样，多样性逐级递减 |
| 美洲原住民 | **最低** | 经白令海峡迁徙的最后一站，经历了最多次级联抽样 |

**机制解释**：每一次进入新的地理区域，只有一小部分先民"抽样"了源群体的遗传多样性。这不是一次性的瓶颈，而是**逐级压缩**——每一级只继承上一级的部分变异，最终形成与地理距离高度负相关的 π 值梯度。这一全球 π 值分布模式，是非洲起源假说（Out of Africa hypothesis）最有力的遗传学证据之一。

> **延伸阅读**：奠基者效应是瓶颈效应的一种特殊形式，其基本机制见 `../01_基础概念/04_遗传变异.md` 第三节。

## 四、固定概率与选择-漂变边界

一个新产生的突变在群体中最终被固定（频率达到 100%）的概率，取决于它受到的选择压力与漂变强度的相对大小。这是群体遗传学最核心的判别准则。

### 不同突变的固定概率

| 突变类型 | 固定概率 | 含义 |
| -------- | -------- | ---- |
| **中性突变** | $P = \dfrac{1}{2N_e}$ | 在大群体中（$N_e$ 大），单个中性突变几乎不可能固定；在小群体中，随机漂变使其"上位"的机会显著增加 |
| **有益突变** （$s$ 较小） | $P \approx 2s$ | 即使是有益突变，在刚产生时也**极易因随机漂变而丢失**——选择优势需要一定时间才能"掌控"频率轨迹；当 $s$ 较小时（$s \ll 1$），$2s$ 仍然是一个很小的概率 |

### 选择-漂变边界：$s$ vs $1/N_e$

判定一个突变是受选择驱动还是受漂变支配，取决于 **$s$（选择系数）** 与 **$1/N_e$（漂变强度）** 的相对大小：

#### A. 大群体（$N_e$ 大，如细菌、昆虫）

- **条件**：$s \gg 1/N_e$
- **特征**：遗传漂变的"噪音"极低——自然选择极其灵敏
- **结果——选择主导**：极微小的有益突变（很小的 $s$）也能被选择识别并固定；极微小的有害突变也被无情剔除
- **基因组特征**：基因组的"洁净度"高，几乎不存在轻微有害变异的积累

#### B. 小群体（$N_e$ 小，如人类、大型哺乳动物）

- **条件**：$s \ll 1/N_e$
- **特征**：遗传漂变的"噪音"巨大——淹没了微弱的选择信号
- **结果——漂变主导，进入准中性 (Nearly Neutral) 区间**：
  - **弱有益突变**：可能因为运气不好（随机漂变）而丢失——即使 $s > 0$
  - **弱有害突变**：可能因为运气好（随机漂变）而固定——即使 $s < 0$

**核心推论**：这解释了为什么人类和大型哺乳动物（$N_e$ 长期较小）基因组中积累了大量的"垃圾"序列和轻微有害变异——这些变异的 $|s|$ 太小，低于 $1/N_e$ 的检测阈值，自然选择对它们"视而不见"，任由漂变决定其命运。

> **延伸阅读**：中性理论（Neutral Theory）和近中性理论（Nearly Neutral Theory）由木村资生（Motoo Kimura）和大田朋子（Tomoko Ohta）分别提出，是上述漂变-选择边界的理论框架。分子钟（molecular clock）的推导（$k = \mu$）等深层内容属于分子进化的理论核心，建议在"分子进化"主题仓库中做全面展开。

## 五、漂变屏障：为什么突变率无法降至零

第四节的选择-漂变边界可以自然延伸到一个更根本的问题：**为什么不自然选择把突变率压到零？**

从表面看，大多数突变是有害的，降低突变率理应具有选择优势。现实中所有生物都维持着一定的突变率，说明自然选择的力量存在**根本性的极限**——这一极限由三重约束共同定义。

### 1. 能量与代谢代价 (Metabolic Cost)

高精度的 DNA 修复（如多层校对 proofreading、核苷酸切除修复 NER）需要消耗大量 ATP 和生物合成资源。细胞在修复上的投入存在**"边际递减效应"**——当修复精度已经很高时，为再减少 1% 的错误可能需要投入成倍的能量。在资源有限的环境下，将这部分能量分配给生长、繁殖或防御，往往比追求"零错误率"更有利于整体适合度。

### 2. 漂变屏障 (Drift Barrier)

当突变率已经降低到足够低的水平后，进一步降低突变率带来的"生存优势"——即对应的选择系数 $s$——变得**极其微小**。如果这个微小的 $s$ 小于漂变强度 $1/N_e$，自然选择就**无法"看见"**这个改进——此时随机漂变完全主导修复系统的演化轨迹，使得修复精度无法进一步优化。

这就是**漂变屏障**的核心逻辑：选择的"视力"受 $N_e$ 限制，任何 $|s| < 1/N_e$ 的微小改良都不可被选择触及。

### 3. $N_e$ 如何决定物种的基线突变率

漂变屏障的强度和物种的有效群体大小直接挂钩：

```text
小 Ne（脊椎动物）
  → 漂变强 → "选择的眼睛"模糊
  → 无法清除稍不精确的修复酶
  → 突变率维持在较高水平

大 Ne（细菌、原核生物）
  → 漂变弱 → 自然选择极其高效
  → 能识别并保留更精准的修复机制
  → 突变率被压制到极低水平
```

**实证对应**：细菌的每代每碱基突变率通常在 $10^{-10}$ 量级（极低），而人类的对应值约为 $10^{-8}$——相差约 100 倍。这一差异与细菌的 $N_e$ 远超人类（细菌 $N_e$ 可达 $10^8$–$10^{10}$，人类长期 $N_e \approx 10^4$）的预测方向完全一致。

## 六、漂变的可量化后果

### 1. 杂合度衰减 (Decay of Heterozygosity)

在有限群体中，由于漂变导致的等位基因随机丢失，杂合度随世代**指数衰减**：

$$H_t = H_0 \left(1 - \frac{1}{2N_e}\right)^t$$

其中 $H_0$ 为初始杂合度，$H_t$ 为 $t$ 代后的杂合度。$N_e$ 越小，衰减越快。

与近交的等价关系：每代因漂变导致的近交系数增量为 $\Delta F = \frac{1}{2N_e}$。

**例题**：$N_e = 500$，$H_0 = 0.4$，100 代后：

$$H_{100} = 0.4 \times \left(1 - \frac{1}{2 \times 500}\right)^{100} = 0.4 \times (0.999)^{100} \approx 0.4 \times 0.905 = 0.362$$

### 2. 等位基因固定概率与时间

在中性演化条件下，初始频率为 $p$ 的等位基因最终固定概率 $= p$——一个频率为 1% 的等位基因有 1% 的概率最终取代所有其他等位基因。

从一个新产生的单拷贝中性突变起，固定时间的期望为：

$$\bar{t}_{fix} \approx 4N_e \text{ 代}$$

丢失时间的期望为：

$$\bar{t}_{loss} \approx 2\ln(2N_e) \text{ 代} \quad (\text{远短于固定})$$

这意味着绝大多数中性新突变在极早期就会被漂变快速淘汰，极少数"幸运"的突变则需要约 $4N_e$ 代才能固定——在人类中（$N_e \approx 10^4$），这约为 4 万代、近 100 万年。

> **延伸阅读**：溯祖理论从相反的时间方向（从当代向过去追溯）描述了同一漂变过程的数学框架，见 `07_溯祖理论.md`。
