# 近亲繁殖与遗传负荷 (Inbreeding & Genetic Load)

HWE 的五大假设之一是"随机交配（Random Mating）"——即群体中任何两个异性个体结合的概率完全均等。近亲繁殖是对这一假设的直接违反。

---

## 一、近亲繁殖的核心机制

**近亲繁殖并不创造有害突变**——突变由 DNA 复制错误和诱变因素产生（见 `../03_突变与重组/01_突变的分子机制.md`）。近亲繁殖的角色是这些有害突变的**"放大器"**：

**风险机制**：近亲交配使基因组迅速**纯合化（Homozygosity）**。

每个个体都携带一定数量的**隐性有害等位基因**，在远交群体中，它们以杂合状态安然存在——正常等位基因的显性效应足以维持功能。但当近亲交配使两个相同祖先来源的隐性有害突变通过血缘传递"相遇"成为纯合体时，致病效应立即爆发。

---

## 二、等位基因同源的三个层次：IBS / IBD / IBO

在讨论近交和遗传负荷之前，需要先建立比较等位基因的基本逻辑框架。群体遗传学使用三个递进的概念描述两个等位基因"相同"的不同含义：

### IBO（同源一致性, Identical by Origin）

**定义**：从一个群体中抽取的多个等位基因，都来自**同一个基因座（locus）**。

IBO 定义了比较的**范围和基础**——我们只有在比较同源（来自同一基因座）的等位基因时，讨论它们是状态相同还是血统相同才有意义。例如，从人群中抽取 100 个"眼睛颜色"基因座的等位基因——它们首先必须是 IBO 的，才能进一步讨论彼此之间的 IBS 或 IBD 关系。

### IBS（状态一致, Identical by State）

**定义**：两个等位基因的当前 DNA 序列**完全相同**，而不关心它们的来源或演化历史。

这是最基础、最直观的比较层次。例如，两个人都携带 A 型血的等位基因，序列完全一致——则它们是 IBS 的。但追溯其远古祖先，这两个等位基因可能来自完全不同的演化谱系（一个来自非洲祖先，另一个来自欧洲祖先），仅仅是因为突变或重组碰巧产生了相同的序列。

### IBD（血统一致, Identical by Descent）

**定义**：两个等位基因不仅状态（序列）相同，而且源于**同一个共同祖先的同一个等位基因拷贝**——它们是该祖先等位基因的"复制品"。

这是最严格的同源标准。例如，父子之间——孩子的一对等位基因中，必有一个来自父亲；这个等位基因与父亲体内的对应拷贝就是 IBD 关系（两者是同一 DNA 分子在减数分裂后进入不同生殖细胞的"分身"）。

### 三者的逻辑关系

> **所有 IBD 的等位基因一定也是 IBS 的，但 IBS 的等位基因不一定是 IBD 的。**

IBD 要求家系可追溯的同源关系；IBS 只要求序列匹配。两个等位基因可以因为独立突变恰好变成相同序列（IBS 但不 IBD），但来自同一祖先拷贝的两个等位基因在没有新突变的情况下必然序列相同（IBD → IBS）。

IBO 则是前提条件——只对来自同一基因座的等位基因做 IBS/IBD 比较才有生物学意义。

---

## 三、近交系数 (Inbreeding Coefficient, $F$)

### 定义

$F$ 量化了一个个体从共同祖先那里继承两个**IBD** 等位基因的概率——即同一祖先的同一个等位基因经过两条不同的血缘路径传递给子代，在子代中"重逢"为纯合体的概率。简言之：**$F = P(\text{两个等位基因是 IBD})$**。

### $F$ 对基因型频率的影响

在近交群体中，HWE 的基因型频率需要修正为：

| 基因型 | HWE 期望（$F = 0$） | 近交群体（$F > 0$） |
| ------ | ------------------- | ------------------- |
| 显性纯合 (AA) | $p^2$ | $p^2(1-F) + pF$ |
| 杂合 (Aa) | $2pq$ | $2pq(1-F)$ |
| 隐性纯合 (aa) | $q^2$ | $q^2(1-F) + qF$ |

**核心模式**：$F$ 越大 → 杂合子比例 $2pq(1-F)$ 越低 → 纯合子比例增加。当 $F = 1$（完全近交），杂合子消失，群体全部为纯合体。

### $F$ 的取值与场景

| $F$ 值 | 场景 |
| ------ | ---- |
| $F = 0.25$ | 同胞兄妹交配产生的子代（亲缘系数 $r = 0.5$ → $F = r/2$） |
| $F = 0.0625$ | 表兄妹（first cousins）婚配的子代 |
| $F = 0$ | 随机交配群体 |

## 四、遗传负荷 (Genetic Load)

### 定义

遗传负荷是指群体中因存在**有害等位基因**而导致的群体平均适合度（fitness）相对于理想最优基因型的降低比例。

### 近交衰退 (Inbreeding Depression)

当近交使隐性有害突变纯合暴露时，受影响的个体在多个适合度维度上显著下降——这种现象称为**近交衰退**：

- 生存力下降（幼体死亡率上升）
- 繁殖力降低（产仔数减少）
- 对疾病和环境胁迫的易感性增加

在野生群体中，近交衰退是濒危小种群面临的核心威胁之一——小种群本身就因漂变导致 $N_e$ 极低（见 `02_遗传漂变与有效群体大小.md`），近交进一步加剧适合度下降，形成"灭绝漩涡（extinction vortex）"的正反馈。

### 遗传清除 (Genetic Purging)

长期近交也有其反面效应：持续纯合化将隐性有害等位基因暴露于自然选择的"视野"中——纯合体因适合度低被淘汰，连同有害等位基因一起从群体中**清除**。因此，经历了长期近交历史的群体（如某些自交植物）尽管遗传多样性极低，但遗传负荷也相应降低——有害突变已被"洗掉"。

---

## 五、突变-选择平衡 (Mutation-Selection Balance)

遗传负荷并非静止不变的——它是"注入"和"清理"两种对立力量达到动态平衡的结果。

### 两种对立力量

| 力量 | 符号 | 方向 | 机制 |
| ---- | ---- | ---- | ---- |
| **突变压力** | $\mu$ | 注入 | 每一代源源不断地产生新的有害突变 |
| **纯化选择** | $s$ | 清理 | 自然选择识别并剔除降低适合度的突变 |

当新突变的产生速率等于被选择清除的速率时，群体中维持一个稳定的**有害等位基因平衡频率 $q$**。

### 平衡公式

| 遗传模式 | 平衡频率 | 直觉 |
| -------- | -------- | ---- |
| **显性 / 半显性**有害突变 | $q \approx \dfrac{\mu}{s}$ | 杂合体直接暴露于选择，频率被严格压制 |
| **隐性**有害突变 | $q \approx \sqrt{\dfrac{\mu}{s}}$ | 杂合体"隐藏"有害等位基因，清除效率低 → 频率更高 |

**核心推论**：选择系数 $s$ 越小（突变越"弱有害"），均衡频率 $q$ 越高——弱有害突变在群体中停留的时间最长、积累最多，是遗传负荷的主要贡献者。

### 人类的遗传负荷现状

每个健康人平均携带约 **200 个杂合状态的有害突变**（包括明确致病的 LoF 和错义变异），但绝大多数处于以下两种"隐形"状态：

- **受保护的隐性状态**：杂合子中正常等位基因足以维持功能，有害等位基因"潜伏"不被发觉
- **极弱效应状态**：$s$ 极小（远小于 $1/N_e$），个体表型几乎不受影响，选择无法有效清除

这两种隐匿机制解释了为什么看似"健康"的人类基因组其实携带着不可忽视的遗传脆弱性——这些潜伏的有害变异正是近交衰退背后的原始材料：当 $F$ 升高使隐性变异暴露为纯合，或当环境变化使原本"微弱"的效应在新的背景下放大时，遗传负荷就转化为真实的表型代价。
