# 群体结构与基因流 (Population Structure & Gene Flow)

HWE 假设"无群体结构"——所有个体来自同一个随机交配群体。现实中，大多数物种都存在地理或生态上的亚群分化。群体结构系统地偏离 HWE，并可产生被误读为选择信号的特征。

> **前置内容**：HWE 的假设与卡方检验见 `01_哈代温伯格平衡.md`；近交系数 $F$ 的 IBD 定义见 `06_近亲繁殖与遗传负荷.md`。

## 一、Wright 的 F 统计量

Sewall Wright 将"近交"概念从个体层面扩展到群体结构的多个层级，提出了三个分层 F 统计量：

| 统计量 | 全称 | 含义 | 比较层级 |
| ------ | ---- | ---- | -------- |
| **$F_{IS}$** | Inbreeding coefficient within Subpopulations | 个体相对于**所在亚群**的近交程度 | 个体 vs 亚群 |
| **$F_{ST}$** | Fixation index among Subpopulations | **亚群间**的遗传分化程度 | 亚群 vs 总群 |
| **$F_{IT}$** | Overall Inbreeding coefficient in Total population | 个体相对于**总群**的近交程度 | 个体 vs 总群 |

### 三者关系

$$F_{IT} = 1 - (1 - F_{IS})(1 - F_{ST})$$

### 基于杂合度的定义

设 $H_T$ 为总群在 HW 期望下的杂合度（$2\bar{p}\bar{q}$），$\bar{H}_S$ 为各亚群内部期望杂合度的均值：

$$F_{ST} = \frac{H_T - \bar{H}_S}{H_T}$$

**直观理解**：$F_{ST}$ 度量了"因亚群分化而损失"的杂合度占总杂合度的比例。如果所有亚群频率相同（无分化），$\bar{H}_S = H_T$，$F_{ST} = 0$。

### 阈值解释

| $F_{ST}$ | 分化程度 |
| -------- | -------- |
| **0** | 无分化 |
| **0–0.05** | 微弱分化 |
| **0.05–0.15** | 中等分化 |
| **0.15–0.25** | 较强分化 |
| **> 0.25** | 强分化（接近完全隔离） |

### 例题

两个亚群 $p_1 = 0.6$，$p_2 = 0.2$：

- $\bar{p} = 0.4$，$\bar{H}_S = \frac{2 \times 0.6 \times 0.4 + 2 \times 0.2 \times 0.8}{2} = \frac{0.48 + 0.32}{2} = 0.40$
- $H_T = 2 \times 0.4 \times 0.6 = 0.48$
- $F_{ST} = \frac{0.48 - 0.40}{0.48} = 0.167$——中等偏强分化

## 二、岛屿模型：迁移-漂变平衡

岛屿模型（Island Model）描述了一组亚群之间通过**迁移（基因流）** 交换个体的简化场景。每代从整个总群中随机抽取 $m$ 比例的个体迁入每个亚群。

### 平衡状态下的 $F_{ST}$

在**迁移-漂变平衡**下，漂变推动亚群分化（增加 $F_{ST}$），迁移同质化亚群（降低 $F_{ST}$），两者达到平衡：

$$F_{ST} \approx \frac{1}{1 + 4N_e m}$$

其中 $N_e m$ 为**每代有效迁移者数目**（有效基因流强度）。

### 关键阈值

| $N_e m$ | 主导力 | 结果 |
| ------- | ------ | ---- |
| **$N_e m > 1$** | 迁移主导 | 群体趋于同质，$F_{ST}$ 低 |
| **$N_e m < 1$** | 漂变主导 | 群体显著分化，$F_{ST}$ 高 |

**生物学直觉**：每代只要有一个以上的有效个体在亚群间迁移（$N_e m > 1$），就足以防止漂变驱动的完全分化。

## 三、基因流的演化效应

基因流（Gene Flow）——个体或配子在群体之间的移动——是连接群体遗传学与宏观演化的关键力：

| 效应 | 说明 |
| ---- | ---- |
| **同质化** | 基因流消除群体间的等位基因频率差异 |
| **引入变异** | 将新等位基因从一个大群体引入到小群体中 |
| **阻碍局域适应** | 迁入个体携带的非适应等位基因"稀释"了本地适应性 |
| **拯救小群体** | 遗传拯救（genetic rescue）——迁入增加小群体的遗传多样性和适合度 |

## 四、杂交渗入：基因流跨越物种边界

前述三节讨论的是同一物种内亚群之间的基因流——它们在演化上尚未形成完全的生殖隔离。但当基因流发生在**已分化的近缘物种之间**时，被称为**杂交渗入（Introgression）**——通过杂交和反复回交，将一个物种的等位基因引入另一个物种的基因库。

与经典基因流的区别：渗入跨越了物种边界——两个群体在演化上已分化到足以被认为是独立物种或亚种，但生殖隔离尚不完全。

### 尼安德特人基因渗入现代人类

现代人类（*Homo sapiens*）走出非洲后，与尼安德特人（*Homo neanderthalensis*）发生了多次基因交流——这是群体遗传学中渗入研究最具影响力的案例。

**关键事实**（Green et al. 2010, *Science*）：

| 人群 | 尼安德特人 DNA 比例 |
| ---- | ------------------- |
| 非非洲裔现代人 | **~1–2%** |
| 非洲裔现代人 | 极低（无直接尼安德特人接触史） |
| 美拉尼西亚人 | 另含 **~2–5%** 丹尼索瓦人（Denisovan）DNA |

**渗入基因的功能意义**：

| 功能类别 | 效应方向 | 具体表现 |
| -------- | -------- | -------- |
| **免疫防御** | 正面 | 多个 HLA（人类白细胞抗原）等位基因来自尼安德特人——可能提升了早期现代人对欧亚大陆新病原体的免疫防御能力 |
| **皮肤与毛发** | 正面 | 部分渗入基因可能帮助适应高纬度环境（紫外线较弱、气温较低） |
| **血液凝固** | 负面 | 部分渗入等位基因增加静脉血栓风险 |
| **神经系统** | 负面 | 部分渗入基因变异与抑郁风险增加相关 |

这种"有益 + 有害"的双重效应是渗入的典型特征——一个在尼安德特人中可能属于中性的等位基因，在被引入现代人类的遗传背景后可能产生预料之外的负面多效性（见 `../06_功能与演化/01_编码区变异的功能后果.md` 第五节）。

### 渗入是"演化捷径"

渗入的演化本质：与其等待一个新突变在群体中产生并被选择打磨数万代，不如**直接从邻近物种"进口"已经被长期选择优化过的功能等位基因**。这是一种"遗传捷径"——现代人类没有必要重新发明抗寒皮肤或抗病原体免疫基因，因为尼安德特人已经在欧亚大陆用了数十万年来适应这些环境。

这一逻辑也解释了为什么渗入的发生并非随机的——渗入的基因通常在**免疫、代谢、环境适应**等功能类别中富集，而在管家基因和发育调控基因中极为罕见（因为这些基因的多效性约束太强，任何外来等位基因都可能破坏精密调控网络）。
