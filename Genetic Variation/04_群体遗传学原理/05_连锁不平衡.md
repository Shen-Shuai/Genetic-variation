# 连锁不平衡 (Linkage Disequilibrium, LD)

## 定义

**连锁不平衡（LD）** 是指在群体中，不同位点（Loci）上的等位基因（Alleles）之间存在的**非随机关联**现象——即某些等位基因组合在群体中出现的频率，显著高于或低于随机组合的预期值。

- **连锁平衡（Linkage Equilibrium, LE）**：若两个位点的等位基因独立分配、随机组合，则处于连锁平衡状态——位点 A 的某个等位基因不会提供位点 B 的任何信息
- **连锁不平衡（LD）**：若某些等位基因倾向于"打包出现"，则存在 LD——知道位点 A 的等位基因状态，就能部分预测位点 B

### 物理基础

LD 通常源于位点在染色体上的**紧密连锁**（物理距离近），导致两点之间的重组率 $r$ 极低。在低重组区，等位基因组合历经多代仍未被交叉互换打散，倾向于作为一个整体（即单倍型块，见 `../01_基础概念/05_单倍型.md`）遗传给下一代。距离越近 → 重组越少 → LD 越强。

## 量化指标

### $D'$（标准化连锁不平衡系数）

$D'$ 主要反映群体的**重组历史**——即两个位点之间是否曾发生过重组。

- **$D' = 1$**：在该群体历史中，两个位点间从未发生过重组（完全连锁）。此时两个位点的等位基因组合虽然可能不是 100% 预测关系（因为可能存在多次独立突变），但重组从未将两者拆散
- **$D' = 0$**：完全连锁平衡

$D'$ 对等位基因频率差异不敏感，因此在比较不同群体或不同频率区间时表现稳定，但对小样本和稀有等位基因非常敏感。

### $r^2$（相关系数平方）

$r^2$ 是**生物信息学和 GWAS 中最常用**的 LD 度量，衡量一个位点对另一个位点的**统计预测能力**。

- **$r^2 = 1$**：完全 LD——两个位点的基因型信息完全冗余，知道 A 就等于知道 B（前提是两个位点的等位基因频率相同且完全共分离）
- **$r^2 = 0$**：完全连锁平衡——两个位点完全独立

$r^2$ 对等位基因频率差异非常敏感——只有当两个位点的等位基因频率相近且处于同一单倍型背景时，$r^2$ 才能达到 1。这一特性使 $r^2$ 成为 Tag SNP 选择（见 `../01_基础概念/05_单倍型.md`）和 GWAS 功效计算的核心参考。

### $D'$ vs $r^2$ 的选用原则

| 场景 | 推荐指标 | 原因 |
| ---- | -------- | ---- |
| 重构重组历史、检测重组热点断点 | $D'$ | 对重组事件敏感，不受等位基因频率差异干扰 |
| Tag SNP 选择、GWAS 关联分析、插补（imputation）评估 | $r^2$ | 直接衡量位点间的预测关系，衡量"用一个位点替代另一个会丢失多少信息" |
